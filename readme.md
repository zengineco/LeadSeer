A desktop application that finds local businesses with no web presence, which
is the shortest possible qualification for a web design lead: they cannot
already have a designer.

**Archived.** It works and it is not being developed. The code is here because
a tool that answers a real question is worth keeping readable.

## What is in here

| | |
|---|---|
| `main.js`, `preload.js` | the Electron shell |
| `src/`, `public/` | the interface |
| `assets/` | icons and the banner |

Run it from source with Node and Electron installed. There has never been a
packaged installer for it.
